# 池袋店 スタイリスト分析ダッシュボード

ビューティーメリットのデータから、**スタイリスト個人と店舗全体の指標**を出し、
**フィードバック文まで自動で作る**ツールです。

## 何が見られるか

| タブ | 内容 |
|---|---|
| 店舗全体 | 純売上・客数・客単価・次回予約率・トリートメント装着率・店販・キャンセル率／予約経路の内訳／売上の推移／自動フィードバック |
| スタイリスト比較 | 全員の指標を一覧で比較（目標達成は緑、伸びしろは赤）／次回予約率のランキング |
| 個人カルテ | 1人分の指標＋前月比＋強み・伸びしろ・次の一手 |
| AIに聞く | いま選んでいる月の数字について、ことばで質問できる（設定したときだけ出る） |

対象月はプルダウンで切り替えられます。

「AIに聞く」の準備のしかたは [worker/README.md](worker/README.md) にまとめています。
Cloudflare Workers AI を使っていて、無料枠のままで 1日およそ200回まで質問できます。

## 使い方

```
./refresh.sh
```

これだけで「最新データの取得 → ダッシュボードの再作成」まで走ります。
出来上がった `dashboard.html` をブラウザで開いてください。

取得済みの月はスキップされるので、毎月動かしても新しい月だけが追加されます。

## ファイル

| ファイル | 役割 |
|---|---|
| `analyze.py` | cache のデータを指標に変換する |
| `feedback.py` | 指標からフィードバック文を組み立てる（目標値もここ） |
| `build_dashboard.py` | HTML を書き出す（デザイン・レイアウト） |
| `dashboard.js` | 画面の切り替え・描画 |
| `refresh.sh` | 取得から作成までをまとめて実行 |

データの取得は `~/Downloads/beauty_merit_report 3/` の仕組みを使っています。
取得したデータは同フォルダの `cache/` に月ごとに貯まります。

## 目標値を変えるには

`feedback.py` の先頭にあります。

```python
TARGET = {"rebook_rate": 10.0, "treat_rate": 5.0, "goods_per": 400.0, "cancel_rate": 20.0}
```

- `rebook_rate` … 次回予約率（%）
- `treat_rate` … トリートメント装着率（%）
- `goods_per` … お客様1人あたり店販（円）
- `cancel_rate` … キャンセル率の上限（%）

フィードバックの文面も同じファイルにあります。言い回しを変えたいときはここを直してください。

## 指標の定義

- **次回予約率** … 予約経路が「次回予約」の件数 ÷ 有効予約件数（キャンセルを除く）
- **トリートメント装着率** … メニュー名に「トリートメント」等を含む予約 ÷ 有効予約件数
- **店販/客** … 商品売上 ÷ 総客数
- **キャンセル率** … キャンセル＋無断キャンセル ÷ 全予約件数
- **稼働スタイリスト** … その月の総客数が20人以上の人

## 注意

- **スタッフ個人の実績を含みます。** 共有範囲にご注意ください。
- 数値の最終確認は、ビューティーメリットの管理画面でお願いします。
- 当月を取り込む場合、その月はまだ途中の数字です（前日までの集計になります）。

※これは一般的な情報です。実際の判断は、専門家（弁護士・税理士など）に必ずご確認ください。
